# ISXS Mini Manual

Mini manual visual de **IllicitSpeed XS**.

## Navegación

- **1 toque:** avanzar una página.
- **2 toques rápidos:** retroceder una página.
- La app completa está girada **-90°** de forma intencional.
- La secuencia va de `R1.png` a `R15.png`.
- Al llegar a `R15.png`, un toque adicional no reinicia el manual.
- En `R1.png`, un doble toque permanece en la primera página.

## Archivos

Las imágenes se cargan directamente desde la raíz del repositorio:

`R1.png`, `R2.png`, …, `R15.png`.

## Pruebas en computador

También se puede navegar con teclado:

- Flecha derecha / abajo / espacio: avanzar.
- Flecha izquierda / arriba / retroceso: volver.
